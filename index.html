Four public dashboards

Each one is a page we already publish, with its data frozen to a single day's snapshot — no network calls, no API key, nothing a visitor can spend. Every page carries a Build my own button that hands over a prompt: paste it into Claude with the FocusAlpha connector and the live version builds itself, on the visitor's own universe and account.

The source of all four, and the live version of each page, is public on github.com/focusAlpha/dashboards (MIT).
