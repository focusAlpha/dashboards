# Get in Claude: the FocusAlpha guide page

The guide page published at [focusalpha.ai/get-in-claude](https://focusalpha.ai/get-in-claude/): the prompt to paste first, sample questions that open in Claude, what the data covers, and the three sample dashboards in this repository with their **Build my own** prompts.

- **[index.html](index.html)** — the page. No data inside; every link opens Claude or one of the samples.
- The three **Build my own** buttons carry the same prompts as the samples' own modals: fetch that dashboard's `live.html` from this repository, publish it with the FocusAlpha connector declared, then apply your conditions.

To get connected: [focusalpha.ai/start](https://focusalpha.ai/start).
