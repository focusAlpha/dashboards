Build me a live screening dashboard from the FocusAlpha sample at https://focusalpha.ai/screener-dashboard, on my own filters.

The page is open source. Fetch this ONE file and use it verbatim as the page:
  https://raw.githubusercontent.com/focusAlpha/dashboards/main/screener-dashboard/live.html
It is a single self-contained HTML file, about 70 KB, no build step, no dependencies. Download it
exactly as it is, with curl or your fetch tool. Do not summarise it, retype it, or rebuild it from
memory. The sample on focusalpha.ai is this same page with a data snapshot frozen on 2026-09-23
baked in; live.html is the same page reading through the FocusAlpha connector instead.

Then, in this order:
1. Publish the file as an artifact, declaring the connector:
     capabilities: { mcp: { servers: [{ server: "FocusAlpha", tools: ["screen_companies"] }] } }
   If the connector is listed in your tools as "focusalpha", use that spelling for server.
   Without this declaration window.claude.use('mcp') resolves null and the page can never fetch.
2. Open it and check that the status line says live and the table has rows. If the page says the
   connector is not available, I have to connect FocusAlpha first: https://focusalpha.ai/start
3. Now change it for me. The default screen is PRESETS[0] near the top of the script, and its
   parameters are the ones the API takes (market_cap_usd_gte, guidance_better_90d_gte, ret_3m_lte,
   sort, ...). Put my conditions below in as the first preset, republish, and send me the link.

Rules for any change:
- Keep the data layer exactly as it is: every read goes through MCP.callTool(SERVER, TOOL, params).
  Never paste rows into the page. The point of this page is that it fetches its own data.
- Before adding a filter, call screen_companies({ list_facets: true }) once. It is free and it gives
  the exact spelling of every country, sector, exchange and event family. Do not guess field names.
- Units: margins, yields and growth are FRACTIONS (0.15 = 15%); price returns are percents.
- A guidance RAISE means a number went up. GOOD NEWS means better for the company. A cost line
  raised is both. The page keeps them in separate columns; keep it that way.

My conditions (edit these):
  market_cap_usd_gte: 5000000000
  guidance_better_90d_gte: 1
  ret_3m_lte: 0
  sort: "guidance_better_90d"
